# megaartaiking-cmd

**AI agent skills, offline tools, and a lightweight video editor — built for real PCs, not just powerful ones.**

I build open-source tools that work offline, stay lightweight, and run on low-end hardware. My main work is Agent Skills: small, composable skill bundles that let AI coding agents (Claude Code, Cursor, GitHub Copilot, Codex, Gemini CLI) do real jobs — edit video and audio, work with CSV, JSON, Markdown, SQL, Git, text, and files — with no cloud and no heavy app.

## Featured project

### 🎬 [LiteCut Pro](https://github.com/megaartaiking-cmd/LIGHT-CUT-VIDEO-EDITOR) — offline video editor for Windows 10
Lightweight video editor that runs on low-end PCs (512 MB RAM, single-core). Trim, split, titles, filters, export WebM/MP4. No Premiere, no cloud.
- [LiteCut Pro 1.0.0 release](https://github.com/megaartaiking-cmd/LIGHT-CUT-VIDEO-EDITOR/releases/tag/v1.0.0)

### 🤖 [openmuseai](https://github.com/megaartaiking-cmd/openmuseai) — unofficial Muse AI desktop app
Lightweight desktop app with built-in proxy config and VPN import for flexible connectivity.

## Why offline and lightweight?

Most tools assume a fast PC and a fast connection. Mine don't. They are built for older Windows 10 machines and for people who want their files to stay on their own computer.
